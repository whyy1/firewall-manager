# SMB 管理功能规划

## 目标与边界

在不改变现有防火墙规则和常用端口业务逻辑的前提下，增加本机 Windows SMB 服务与共享目录管理。所有写操作均要求管理员权限，并由界面明确提示影响。

本轮不修改 NTFS 权限、不启用 SMB1、不管理远程计算机，也不在自动化测试中改动真实服务或共享。

## 功能清单

### P0：本轮交付

- SMB 概览
  - 显示 `LanmanServer` 服务运行状态与启动类型。
  - 显示 SMB1、SMB2/3、服务端签名要求和全局加密状态。
  - SMB1 仅允许关闭，不提供启用入口。
- 服务管理
  - 启动或停止 SMB 服务。
  - 停止前提示现有共享连接会中断。
- 共享管理
  - 列出普通共享与系统特殊共享。
  - 创建共享，支持只读、更改、完全控制三种共享权限，默认只读。
  - 删除普通共享；系统特殊共享不可删除。
  - 明确说明共享权限不会自动修改 NTFS 权限。
- 安全与可诊断性
  - 后端校验共享名、目录、权限级别和系统保留名称。
  - 参数通过进程环境传给 PowerShell，避免拼接用户输入。
  - PowerShell 使用结构化 JSON 输出，避免依赖本地化文本解析。
  - 写操作失败时返回包含操作上下文的错误。
- 界面集成
  - 侧边栏增加“SMB 管理”。
  - 加载、空状态、错误状态和操作中状态清晰可见。
  - 危险操作使用二次确认。

### P1：本轮交付

- 查看活动 SMB 会话，并按会话断开连接。
- 查看文件和打印机共享防火墙规则在各配置文件中的有效状态；为避免规则跨配置文件联动造成误判，启停时统一切换整个规则组。
- 在共享列表同时显示本机目录和 `\\计算机名\共享名` 网络访问地址。
- 可直接用资源管理器打开本机目录或网络共享。
- 只读检测 Windows 当前已连接或映射的局域网磁盘共享，并直接打开检测结果。
- 检测不读取共享内文件，也不主动探测未连接设备；空结果不代表局域网没有共享。

### P2：后续增强

- 创建共享时选择具体用户或组，而不是内置 Everyone 主体。
- 管理共享级加密、签名和来宾访问安全策略。
- 编辑现有共享的权限与描述。
- 增加操作审计记录、配置导出和恢复。

## 验收标准

1. 进入 SMB 页面后，可以看到服务、协议安全状态和共享列表。
2. 单条共享时仍以数组正确显示，系统特殊共享无法删除。
3. 非法共享名、非绝对目录、不存在目录和非法权限级别会在执行命令前被拒绝。
4. 创建共享默认使用只读共享权限，且用户输入不进入 PowerShell 脚本文本。
5. 停止服务、删除共享和关闭 SMB1 均需二次确认。
6. 单元测试不启动/停止服务，不创建/删除真实共享。
7. `go test ./...`、`go vet ./...` 和前端生产构建通过。
8. 本机共享可分别点击打开磁盘目录和网络访问地址。
9. 已连接共享检测为空时明确说明不代表局域网没有共享；检测失败不会影响本机共享管理。
10. 活动会话断开和防火墙规则切换均要求管理员权限及二次确认。
