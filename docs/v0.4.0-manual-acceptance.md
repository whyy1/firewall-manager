# v0.4.0 管理员实机验收清单

日期：2026-10-10。当前为节点一，待用户执行。自动验收及浏览器模拟通过不代表以下实机项目通过；关键项目失败或未验证时不正式发布。

## 验收环境与基线

- 使用隔离 Windows 测试机或虚拟机，本地管理员登录，先创建可恢复的虚拟机检查点。记录 Windows 版本、应用 SHA-256、测试人、日期及结果。
- 使用 build/bin/firewall-manager.exe 最新构建，关闭旧程序后启动。此构建用于验收，正式 v0.4.0 版本元数据和发布文件在实机通过后准备。
- 规则及共享只使用专门创建的测试对象，例如 FM-Acceptance-20261010；目录只用本机新建的空测试目录，文件仅含非敏感测试内容。不要选择生产规则、共享或生产目录。
- 记录 LanmanServer、TermService、WinRM 初始状态与启动类型；记录 RDP 注册表真实 PortNumber、WinRM HTTP 监听器真实端口，以及共享防火墙组各规则初始启用状态。端口表检测值是参考，不能替代真实配置基线。
- 导出 RDP-Tcp 配置及防火墙策略作为恢复资料，记录 WinRM HTTP 监听器属性。不通过远程 RDP/WinRM 会话测试对应端口变更；必须具备本地控制台或虚拟机控制台。
- 以下系统写操作全部由用户主动执行，助手没有执行。共享、服务及端口修改可能中断连接；VM 检查点用于完整恢复，单个项目结束后也应恢复测试状态。

## 项目、影响、预期及恢复

|---|---|---|---|---|
| C1 | 查看三页，在 800×500、1100×700、1440×900 及明暗主题使用键盘导航 | 无配置写入 | 页面、表格横向滚动和操作列正常；长名称/路径可查看；抽屉和弹窗内容与按钮可通过滚动访问 | 关闭弹窗，恢复原窗口尺寸和主题 |
| F1 | 入站/出站刷新；按名称、地址、端口筛选与清空；跨 50 条分页检查 | 只读 | 搜索命中完整数据，统计准确，切换方向不被旧结果覆盖；记录每个方向规则数、查询耗时，完整查询须在 30 秒内返回，否则验收暂停 | 清空筛选 |
| F2 | 新增唯一测试 TCP 入站规则：仅回环地址、未占用测试端口、专用配置文件，初始禁用 | 添加测试规则 | 刷新后存在一条，Windows 高级防火墙中属性一致；非法地址提交被拒绝 | 删除且仅删除该测试规则 |
| F3 | 编辑测试规则地址、端口、配置文件及启用状态；验证服务、规则组、安全属性未编辑时保持 | 改变测试规则 | 原规则被更新而非新增；属性与界面一致，没有同名新对象；启停、删除只作用于所选规则 | 恢复测试规则属性或删除测试对象 |
| F4 | 创建两条同名同方向测试规则，记录各自内部 ID 和来源，分别编辑、启停、删除；在隔离域环境测试策略覆盖同 ID 本地规则及打开表单后来源变化，再测试已删除目标 | 仅改变所选 ID 对应的测试规则 | 同名可新增且可单独管理，另一条保持不变；列表和表单完整展示 ID/来源，只读策略不可写；来源变化、缺失和 ID 歧义明确拒绝，不修改被策略覆盖的本地对象 | 按内部名称逐个清理测试规则；不修改组织策略规则 |
| F5 | 若存在 Internet、LocalSubnet4 等远程地址的可编辑本地测试规则，编辑其他字段 | 改变测试规则的指定字段 | 合法原地址不被拒绝，不变成任意地址；未知地址仍拒绝 | 恢复测试字段或删除测试规则 |
| P1 | 查看 RDP、WinRM、SMB 及仅查看服务 | 只读 | 检测值与默认值分开，零值未检测到；SMB 无修改入口 | 无 |
| P2 | 本地控制台下，将 RDP 从记录的原端口改为一个未占用测试端口，再由另一测试设备连接 | 配置写入、停止/启动服务及可能中断现有远程会话；应用不自动添加新端口防火墙规则 | 真实配置及监听使用测试端口；准备仅限测试客户端地址的临时入站规则后可实际连接；失败明确区分配置写入与服务重启 | 用记录的原值恢复配置，必要时导入备份并手动恢复服务；验证原端口连接，清理临时防火墙规则 |
| P3 | 本地控制台下修改现有 WinRM HTTP 监听器端口，并从测试客户端使用指定端口连接 | 改变 HTTP 监听器、服务重启；可能中断管理连接 | 监听器真实端口一致，实际连接通过；缺失监听器等失败有明确错误，不提示成功 | 将 HTTP 监听器端口恢复原值，恢复服务；验证原端口连接，清理临时规则。HTTPS 监听器不在本次修改范围 |
| P4 | 在隔离环境制造端口写入后的服务重启失败 | 可能已写入配置，但服务未恢复 | 报告具体停止或启动失败，不吞掉错误；保留输入并暂停重复提交，提醒检查服务和恢复配置 | 从本地控制台恢复原配置及初始服务状态，再刷新；不以重复点击代替恢复 |
| S1 | 查看真实服务/协议概览；停止 SMB 服务后刷新，再从页面启动 | 中断 SMB 连接并暂时使共享不可用 | 停止后服务显示已停止，协议未检测，启动按钮可用；共享查询失败不锁住恢复入口；启动后状态和访问恢复 | 保证 LanmanServer 恢复到记录的初始运行状态与启动类型 |
| S2 | 在测试目录创建只读、更改、完全控制共享；从另一测试机访问并对照 ACL | 新增共享及 Everyone 共享权限；不自动修改 NTFS | 默认只读；实际访问同时受共享与 NTFS 权限限制，NTFS ACL 保持；单条与空列表显示正常 | 删除测试共享，仅清理测试目录中的测试文件；保留原目录 ACL，必要时恢复检查点 |
| S3 | 检查系统共享删除保护；删除一个普通测试共享 | 普通共享删除会中断访问；系统共享应保持 | 系统共享按钮不可删除，普通共享确认包含目标；真实普通共享删除生效 | 必要时以记录的目录和权限重建测试共享；最终清理测试共享 |
| S4 | 浏览选择目录；尝试 UNC、设备路径、相对路径、映射网络盘等创建输入；打开合法目录与 UNC | 无效路径应拒绝；合法打开会启动 Explorer 或访问网络地址 | 无效创建不会新建共享；原生目录选择及打开位置正确；任意程序路径不提供打开目录操作 | 关闭 Explorer；取消测试映射连接 |
| S5 | 连接测试共享并查看会话，选择该测试会话断开 | 中断所选客户端连接 | ID 与真实会话一致，二次确认后仅断开目标，刷新显示一致 | 测试客户端重新连接，结束后关闭测试连接 |
| S6 | 在隔离环境切换文件和打印机共享防火墙组并检查域/专用/公用状态 | 整个共享规则组切换，影响所有配置文件；可能改变其他共享连接 | 确认明确整个组范围，界面与有效策略一致；组策略限制不会被宣称已成功绕过 | 按逐规则基线恢复，混合初始状态不能仅用一次整组切换还原；必要时恢复 VM 检查点 |
| S7 | 关闭测试 VM 中已启用的 SMB1，并检查 SMB2/3 访问 | 旧 SMB1 客户端失去访问 | SMB1 实际关闭，SMB2/3 保持可用，重启需求如实记录 | 恢复 VM 检查点；不要为了恢复测试在生产机重新启用 SMB1 |
| S8 | 检测已连接或映射的测试共享，打开结果；断开测试映射再检测 | 检测只读；打开地址可能触发网络访问 | 名称与路径正确；成功为空和失败区分，空结果不宣称局域网没有共享 | 关闭 Explorer，断开测试连接/映射 |
