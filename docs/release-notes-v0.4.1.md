# v0.4.1

## 修复与完善

- 防火墙规则按内部 ID 和策略来源精确管理，允许显示名称重复；编辑、启停、删除仅操作所选唯一可编辑本地对象。身份歧义、来源变化和只读策略拒绝修改。
- 校验本地化地址、协议、端口和配置文件；未知地址不转换成任意。更新仅提交变化字段，保留未编辑的服务、规则组、安全属性及 ICMP 限制。
- 修复端口配置后服务重启失败被忽略的问题，区分配置失败与写入后的恢复失败。RDP 与已有 WinRM HTTP 监听器仍支持修改。
- 纠正 SMB TCP 端口能力：TCP 445 仅查看，不再提供无效的端口修改，也不会自动清理旧版 SmbPort 注册表值。
- SMB 服务停止后保留启动入口；协议、共享及会话查询独立呈现错误。共享路径与权限校验、系统共享保护和危险操作确认得到完善。
- 修复 SMB 打开目录使用隐藏窗口设置的问题，增加打开请求与错误反馈；用户已反馈该修复复测通过。
- 重新组织三个管理页面，统一明暗主题、搜索筛选、权限提示与执行状态；阻止重复提交，保留失败表单，写成功但刷新失败单独提示。
- 更新中英文 README、界面截图、自动验收报告和管理员恢复清单。

## 下载与使用

下载 firewall-manager.exe（Windows amd64），以管理员权限运行；需要 WebView2 Runtime。SHA256SUMS.txt 用于校验同一发布的可执行文件。

## 验证与限制

Go 测试与静态检查、30 项前端单元测试、28 项模拟界面测试及生产/Wails 构建通过。自动化测试不修改真实防火墙、服务、共享或注册表。

模拟测试不替代管理员实机验收。验收报告仍保留未逐项记录的服务恢复、真实共享权限、RDP/WinRM 连接、策略覆盖、SMB1 和会话断开等场景；用户反馈的复测不扩展为全部项目通过。

端口检测为参考信息，不能证明实际连接可用。规则来源仅明确 Local / PersistentStore 时可写，未知来源保守只读；完整管理员规则查询的规模与耗时仍需验证，超过 30 秒会超时。前端构建保留包体积警告。

本版本不覆盖现有 v0.4.0 标签或发布资产。
